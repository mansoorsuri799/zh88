# ZH88 — zh888app.com.pk

Next.js site for **ZH88 Game** APK guides in Pakistan (download, deposit, withdraw, PC, blog).

## Stack

- Next.js App Router + TypeScript
- Tailwind CSS (brand tokens from ZH88 icon: forest primary + gold accent)
- Poppins via `next/font`

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Domain

Canonical host: `https://zh888app.com.pk`
